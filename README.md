Olá, Usuário! — Nome e Idade

Este é um projeto simples desenvolvido para praticar os fundamentos de HTML, CSS e JavaScript.

Ao abrir a página, o usuário informa seu nome e sua idade por meio de caixas de diálogo. Depois, o JavaScript utiliza essas informações para exibir uma mensagem personalizada de boas-vindas.

O projeto também possui uma interface simples criada com CSS, incluindo centralização do conteúdo, bordas arredondadas, sombras e efeito hover no botão.

Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

O que pratiquei

* Estrutura básica de uma página HTML
* Estilização com CSS
* Uso de prompt() para receber informações
* Uso de alert() para exibir mensagens
* Variáveis em JavaScript
* Concatenação de textos
* Eventos com onclick
* Efeito hover com CSS

Objetivo

O objetivo do projeto foi colocar em prática os primeiros conceitos de JavaScript, criando uma página capaz de receber informações do usuário e responder de forma dinâmica.
